# Smart Home System

A C++ console application that simulates a smart home, developed as the OOP course project.

## Description
The system manages home devices (lights, thermostat, camera, and a security system) through a main `SmartHome` object that coordinates them.

## Features
- Turn devices on and off
- Set light brightness and target temperature
- Arm and disarm the security system
- Run a morning routine that coordinates all devices
- Show the status of all devices

## Main Classes
- `Light`: brightness and on/off state
- `Thermostat`: target and current temperature
- `Camera`: recording on/off
- `SecuritySystem`: armed/disarmed state and alarm
- `SmartHome`: manages all devices and routines

## OOP Concepts
- Classes and objects, encapsulation
- Constructors and destructors
- Composition and aggregation, pointers
- Static members
- Inheritance, polymorphism, operator overloading, and exception handling (added as the course progresses)
